# Cybersecurity & Penetration Testing Journey

> Building my cybersecurity skills from the fundamentals to practical penetration testing.

This repository documents my journey into cybersecurity, with a **primary focus on penetration testing and offensive security**.

I am starting from the fundamentals and gradually building practical skills through labs, projects, challenges, and security research.

The goal is not just to complete courses, but to understand **how systems work, how they can be attacked, how vulnerabilities can be identified, and how security weaknesses can be properly documented and reported.**

---

## 🎯 Main Goal

My long-term goal is to become a skilled **penetration tester** with strong foundations in:

* Networking
* Linux and Windows
* Python and Bash
* Reconnaissance
* Enumeration
* Vulnerability assessment
* Web application security
* Privilege escalation
* Active Directory
* Exploitation
* Post-exploitation
* Security reporting

I am following a **learn → practice → build → document** approach.
